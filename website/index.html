Feigram Public

为飞牛 OS 打造的第三方 Telegram 客户端

Feigram 将 Telegram 会话、分组、图片视频预览、下载缓存和多账户管理带到 fnOS 设备上，适合在 NAS 或飞牛设备中自托管使用。

查看官方仓库 加入 Feigram 群
Feigram for fnOS Web + Node.js + MTProto

Features

核心功能

Telegram 多账号

支持多个 Telegram 账号登录、切换、退出，并为不同飞牛账户隔离 session。

聊天与分组

同步 Telegram 会话列表和聊天文件夹，支持搜索、群组、频道、私聊和站内跳转。

媒体预览

支持图片预览、视频在线播放、媒体组展示、群组信息侧栏和最近文件快捷访问。

下载缓存

视频缓存进入统一下载中心，可查看进度、速度、状态，并支持清除列表或删除缓存。

管理员后台

可管理飞牛账户、覆盖 API 设置、缓存目录、通知、隐私、播放器和分组行为。

公开发布准备

内置发布说明、隐私政策、服务条款入口，并明确第三方非官方客户端身份。

Deploy

面向 fnOS 的自托管发布

Feigram Public 以 FPK 形式安装到飞牛 OS。安装后通过管理员后台完成飞牛账户、Telegram 账号、缓存目录和播放器策略配置。

官网页面可直接部署到 Cloudflare Pages，输出目录使用仓库中的 website。

  1. 从 GitHub Releases 下载 Feigram Public FPK。
  2. 在飞牛 OS 中安装并打开应用。
  3. 创建第一个管理员飞牛账户。
  4. 添加 Telegram 账号并开始使用。
