# Fngram 隐私政策

生效日期：2026-06-10

Fngram 是第三方开发的非官方 Telegram 客户端，仅适用于飞牛 OS / fnOS。本文说明 Fngram 在自托管或公开发布环境中如何处理数据。

## 数据控制者

Fngram 的运行者是实际数据控制者。若你从第三方平台安装 Fngram，请以发布者在应用内或仓库中提供的支持邮箱和政策链接为准。

## 我们处理的数据

Fngram 可能在你的飞牛 OS 设备上保存以下数据：

- 飞牛账户名称、显示名、角色、禁用状态和密码哈希。
- Telegram 账号标签、手机号、用户名、显示名。
- 加密后的 Telegram session。
- 聊天列表、消息预览、图片、视频、文件和头像缓存。
- 管理员配置，例如公开访问地址、缓存目录、保留天数、公告和发布信息。
- 服务日志和错误信息。

## 数据用途

这些数据用于：

- 登录 Fngram 和管理飞牛账户。
- 连接 Telegram 并展示会话、消息和媒体。
- 缓存媒体文件以支持预览、下载和降低重复下载。
- 显示公告、支持邮箱、隐私政策和服务条款。
- 排查故障和保障服务安全。

## Telegram 数据

Fngram 通过用户授权的 Telegram session 访问 Telegram。Telegram 消息、媒体、群组、频道和联系人数据受 Telegram 自身政策和服务条款约束。Fngram 不代表 Telegram，也不提供官方 Telegram 服务。

## 数据存储与加密

Telegram session 使用本地密钥加密后存储。飞牛账户密码以哈希形式保存。媒体缓存按照管理员设置的目录和保留天数存放。运行者应妥善保护飞牛 OS 设备、管理员账户、磁盘权限和备份。

## 数据共享

Fngram 默认不将本地数据发送给项目作者。数据会在连接 Telegram 时与 Telegram 服务交互。若运行者额外配置代理、反向代理、监控、备份或第三方存储，应由运行者另行告知使用者。

## 数据保留

管理员可设置聊天缓存自动清理天数。删除飞牛账户、退出 Telegram 账号或卸载应用前，运行者应按需清理本地数据目录和备份。

## 使用者权利

使用者可联系 Fngram 运行者请求查看、删除或更正其飞牛账户和本地缓存数据。实际响应方式取决于运行者部署环境。

## 安全建议

- 使用 HTTPS 公开访问。
- 设置强管理员密码。
- 限制公开注册或仅由管理员创建飞牛账户。
- 定期更新 Fngram 和飞牛 OS。
- 定期检查缓存目录和日志。

## 联系方式

请以应用内或发布仓库中配置的支持邮箱为准。
