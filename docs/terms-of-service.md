# Fngram 服务条款

生效日期：2026-06-10

Fngram 是第三方开发的非官方 Telegram 客户端，仅适用于飞牛 OS / fnOS。使用 Fngram 即表示你同意以下条款。

## 非官方声明

Fngram 不隶属于 Telegram、Telegram Messenger Inc. 或飞牛官方。Telegram 名称、标识和服务归其相应权利人所有。

## 使用条件

你需要：

- 遵守 Telegram 服务条款、飞牛 OS 使用规则和所在地法律法规。
- 仅使用你有权登录的 Telegram 账号。
- 不利用 Fngram 发送垃圾信息、诈骗、侵权内容、恶意软件或违法内容。
- 妥善保管飞牛账户和 Telegram 账号凭据。

## 运行者责任

公开部署 Fngram 的运行者负责：

- 配置 HTTPS、访问控制和安全更新。
- 提供支持邮箱、隐私政策和服务条款。
- 管理飞牛账户、缓存目录、日志和备份。
- 处理使用者的数据访问、删除和安全请求。

## 功能限制

Fngram 尽力接近 Telegram 官方客户端体验，但不保证完整支持所有官方功能。部分视频格式取决于浏览器解码能力，无法播放时可下载后用系统播放器打开。

## Telegram API 配置

公开版包含默认 Telegram API 配置以简化安装。管理员可在后台覆盖 API 设置。任何 API 配置都不应被视为保密安全边界，发布者应自行评估风控、滥用和平台规则风险。

## 免责声明

Fngram 按现状提供，不承诺服务不中断、无错误或完全兼容 Telegram 官方客户端。因使用、部署、公开发布或配置 Fngram 产生的风险由运行者和使用者自行承担。

## 终止

运行者可因安全、滥用、合规或维护原因禁用飞牛账户、停止服务或删除本地数据。

## 联系方式

请以应用内或发布仓库中配置的支持邮箱为准。
