# Feigram Public 发布说明

## 版本 2.0.3

### 修复

- 群缓存任务点击取消后会从列表移除，并同步从持久化任务文件中删除。
- 下载列表遇到 `Request was unsuccessful 5 time(s)` 等 Telegram 网络请求失败时，会自动重试，降低偶发网络波动导致任务直接失败的概率。
- 群缓存使用同样的网络失败识别逻辑，遇到网络波动会重新排队继续缓存。

### 新增

- 群缓存新增排重，优先按同账号、同群、同视频标题和大小去重。
- 群缓存列表支持拖动排序，排序结果会保存到服务端，并作为后台缓存队列顺序。
- 服务端每 10 分钟巡检群缓存任务，失败、暂停、排队或长时间无进度的任务会重新拉起，直到缓存完成。

## 版本 2.0.2

### 修复

- 修复跳转到目标群聊后，消息列表尚未完成渲染时提前清空定位状态，导致无法精准滚动到目标消息的问题。
- 跳转目标消息无法从 Telegram 返回时，会提示“你要访问的内容已被删除”。

### 改进

- 群视频后台缓存控制状态持久化，刷新飞牛访问链接或重新打开窗口后仍能看到缓存任务状态。
- 管理员后台“群缓存”新增一键开启/暂停。
- 群缓存新增最大缓存速率限制，支持不限速、512 KB/s、1 MB/s、2 MB/s、5 MB/s、10 MB/s。
- 群缓存标题后新增 X，可单独取消未完成的后台缓存任务。
- 支持已同步会话中的 `t.me/c/...` 私有群组/频道消息链接在客户端内解析定位。

## 版本 2.0.1

### 修复

- 修复聊天消息中的 Telegram 链接在客户端内打开后，只切换群组但无法定位到目标消息的问题。
- 修复访问跳转消息后点击返回，无法恢复原聊天阅读位置的问题。
- 修复管理员后台诊断页读取日志时报 `handle.close is not a function` 的问题；该问题只影响诊断日志读取，不影响 Feigram 正常运行。

### 新增

- 管理员后台新增“群缓存”列表，专门展示群组信息页勾选自动缓存后产生的后台视频缓存任务。
- 群缓存列表展示视频标题、缓存进度、缓存速率、状态和更新时间，并保持紧凑布局。
- 群缓存任务继续和下载中心分离；只有用户主动点击缓存的视频才进入下载中心。

## 版本 2.0.0 - fnOS Client Edition

### 定位

- Feigram 2.0 开始按 fnOS Client Edition 方向整合，保留现有 Web + Node.js + FPK 技术路线。
- 目标是让 Feigram 在飞牛 OS 中更接近正式客户端体验：后台服务、日志诊断、更新检测、任务恢复、缓存管理和迁移记录。

### 新增

- 管理员后台新增“诊断”页，可查看版本、版本线、运行时间、缓存大小、任务数量、数据目录和日志尾部。
- 管理员后台新增应用内更新检测，连接 GitHub Releases 获取最新发布信息。
- 新增启动迁移记录，升级后会维护 `app-meta.json`、下载任务和后台缓存任务文件。
- FPK 启动脚本增强日志，记录启动时间、版本线、版本号、端口、数据目录和缓存目录。
- 用户主动下载任务和群组后台静默缓存任务支持落盘，服务重启或版本升级后自动恢复。

### 改进

- 群组后台静默缓存大于 100MB 视频时，最多同时运行 5 个任务，完成后再继续队列中的其他任务。
- 群组信息资源列表支持滚动加载更多，避免只能看到首屏资源。
- 下载任务 ID 改为稳定哈希，便于跨重启恢复和排重。

### 说明

- 主动点击“缓存”的视频仍进入下载中心。
- 群组勾选自动缓存产生的是后台静默任务，不进入下载中心。
- 如果底层 Telegram 下载库无法复用临时分片，恢复任务会自动重新拉取并覆盖临时文件，保证任务不丢失。

## 版本 1.5.9

### 修复

- 下载中心改为按任务创建时间固定排序，下载进度、速度和状态刷新不会改变任务位置。
- 去掉视频窗口上的播放器模式提示，减少聊天信息区域的视觉干扰。

### 新增

- 群组信息中的图片、视频、文件统计卡片可点击筛选资源。
- 群组信息资源区按类似官方客户端的媒体网格展示，可直接打开图片、播放视频或下载文件。
- 群组信息新增“后台自动缓存本群大于 100MB 的视频”开关。
- 视频消息新增封面预览和时长展示，优先读取 Telegram 自带缩略图，缓存后可由 ffmpeg 截帧兜底。

### 缓存策略

- 用户主动点击视频右上角“缓存”的任务仍进入下载列表。
- 群组信息里勾选后台缓存后，服务端会静默缓存最近消息中大于 100MB 的视频，不写入下载列表。
- 静默缓存会跳过已经在下载列表中排队、下载或完成的视频，避免重复拉取。

## 版本 1.5.8

### 修复

- 修复管理员后台表单、账户列表和设置页在部分窗口尺寸下被拉伸变形的问题。
- 修复群组信息侧栏中文件与媒体统计卡片占用大量空间的问题。
- 下载中心移除右键菜单，避免菜单无法自动消失；所有操作改为任务卡片内小按钮。
- 修复同一视频缓存完成后下载列表可能出现多条成功记录的问题。

### 改进

- 下载任务标题使用稳定省略展示，不再循环滚动或抖动。
- 下载速度、进度和更新时间始终可见，无需拖动或悬停。
- 默认播放器策略改为“原始视频在线播放优先”，内置 HLS 转码保留为实验兜底模式。
- 视频和图片消息按稳定最大宽度、横竖比例和媒体组网格展示，减少忽大忽小的跳变。

### 播放策略说明

- Telegram 官方客户端是本地客户端，可以直接使用本机解码能力和本地分段缓存。
- Feigram 运行在 Web 容器中，浏览器不支持的编码无法仅靠前端播放器解决。
- 因此 1.5.8 默认走原始视频在线播放，遇到无法解码的视频时，再由管理员切换到 HLS 转码或本地播放器模式。

### 修复

- 群组信息里的图片、视频、文件支持快捷访问。

### 改进

- 公告弹窗和管理员后台弹窗统一限制高度，内容区滚动，避免遮挡关闭按钮。
- 播放器显示当前播放模式，便于判断正在走内置转码还是浏览器原始播放。

## 版本 1.5.5

### 新增

- 左侧功能栏新增“下载”功能区，所有点击缓存的视频会进入统一下载列表。
- 下载列表展示任务状态、下载进度、已下载大小、总大小和实时速度。
- 下载任务支持开始/继续、取消、删除，右键菜单和按钮操作都可用。
- 视频窗口右上角新增缓存按钮，展示缓存、排队中、下载中、已缓存等状态。

### 改进

- 视频缓存改为后台任务，不再阻塞当前聊天窗口。
- 缓存视频使用 `.part` 临时文件，取消后再次开始会从已写入位置继续。
- 在线播放继续使用 HTTP Range 分块响应，优先播放当前点击的视频。

### 已知限制

- Feigram 当前内置播放器基于浏览器媒体能力。仅替换 JS 播放器无法解码浏览器本身不支持的视频编码；要彻底提升兼容性，需要后续接入服务端 ffmpeg 转码或 HLS 输出。

## 版本 1.5.4

Feigram Public 是第三方开发的非官方 Telegram 客户端，仅适用于飞牛 OS / fnOS 设备。Feigram 不隶属于 Telegram、Telegram Messenger Inc. 或飞牛官方。

### 新增

- 文件夹展示改成左侧竖向分组栏，包含分组图标、名称、会话数量和编辑入口。
- 聊天搜索支持回车提交，输入内容后显示一键清除按钮。
- 群聊消息支持展示发言人头像、名称和 ID，可在管理员后台隐私设置里开关。
- 同一组 `groupedId` 的图片和视频会合并为媒体组网格展示。
- 视频下载不再跳新窗口，改为 Feigram 客户端内缓存；缓存完成后同一条消息优先使用本地缓存播放。

### 改进

- 在线播放去掉强制 `type` 约束，让浏览器自行嗅探视频格式，降低误判不支持的概率。
- 视频仍受浏览器原生解码能力限制。对不支持的编码，Feigram 会优先提供本地缓存播放链路，后续可继续接入转码模块。

## 版本 1.5.0

### 新增

- 同步 Telegram 聊天文件夹，在左侧会话列表上方展示分组。
- 管理员公告栏，前台通知按钮会在有新公告时点亮。
- 公开版内置默认 Telegram API 配置，安装向导不再强制填写 API ID / Hash。
- 管理员后台保留“覆盖 API 设置”能力。
- 视频播放增加浏览器不支持格式时的下载兜底。
- 登录和管理员后台文案统一为“飞牛账户”。
- 补充隐私政策、服务条款和发布说明文档。

### 已支持能力

- 多飞牛账户隔离。
- 每个飞牛账户独立 Telegram session 和缓存目录。
- Telegram session 加密存储。
- 图片、视频、文件缓存下载位置管理。
- 聊天缓存自动清理。
- Telegram 链接客户端内跳转和返回。

### 已知限制

- Telegram 官方客户端的视频播放器不是可嵌入第三方 Web 客户端的组件。本项目使用浏览器原生播放器和 HTTP Range 分段响应；如果视频编码不被当前浏览器支持，请下载后用系统播放器播放。
- Telegram 聊天文件夹中部分动态规则由官方客户端本地组合，Feigram 会尽量同步显式包含、排除和常见类型规则。
- Feigram 不是官方 Telegram 客户端，不保证与官方客户端功能完全一致。

## 发布前检查

- 配置 HTTPS 或可信反向代理。
- 在管理员后台配置支持邮箱、隐私政策 URL、服务条款 URL。
- 检查缓存目录权限和可用磁盘空间。
- 确认使用者知晓这是第三方非官方客户端。
